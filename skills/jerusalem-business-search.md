# חיפוש עסקים בירושלים → אקסל

## מה הסקיל הזה עושה

מחפש עסקים פעילים בירושלים מסוגים שדורשים שטח מסחרי של ממש (לא עסקים שיכולים לפעול מחדר קטן בבית), מאמת כתובת מדויקת לכל עסק, ומייצר קובץ אקסל מעוצב ומסודר.

---

## חוקי הכללה — מה לחפש

### סוגי עסקים מתאימים
עסקים שמטבעם חייבים להשתמש בשטח מסחרי גדול — כגון:
- **מרפאות שיניים** — מרובות כסאות טיפול, ציוד כבד, חדרי המתנה
- **משרדי עורכי דין** — צוות של כמה עורכי דין, ארכיון תיקים, חדרי ישיבות
- **משרדי רואי חשבון** — צוות, ארכיון, חדרי עבודה
- **מרפאות וטרינריות** — חדרי ניתוח, ציוד הדמיה, אשפוז בעלי חיים
- **קליניקות רפואיות / פיזיותרפיה** — חדרי טיפול מרובים
- **משרדי אדריכלים / הנדסה** — שולחנות שרטוט, דגמים, צוות
- **מרפאות עיניים / שמיעה** — ציוד רפואי ייעודי

### סוגי עסקים **לא** מתאימים
- יועצים בודדים שעובדים מהבית
- עורך דין / רואה חשבון בודד ללא כתובת מסחרית מאומתת
- עסקים שיכולים לפעול מחדר קטן בדירה

### חריג חשוב לעורכי דין ורואי חשבון
עורך דין / רואה חשבון בודד **מקובל** אם הכתובת שלו היא בבניין מסחרי מוכר (מגדל, מרכז עסקים, גן טכנולוגי, אזור תעשייה) — כי במקרה כזה ברור שזו כתובת משרד אמיתי ולא דירת מגורים.

---

## חוקי כתובת — כלל ברזל

### מה חובה
- **רחוב + מספר בית** — זה המינימום המוחלט
- שכונה — רצוי אך לא חובה
- **לא** לכתוב "ירושלים" בעמודת הכתובת (כולם בירושלים, זה מיותר)

### מה אסור לכתוב
| אסור | מותר |
|------|------|
| `ירושלים` (ללא רחוב) | `הלל 16` |
| `מרכז העיר` | `שמאי 14` |
| `פרטים באתר` | `יד חרוצים 10, קומה 2` |
| `ירושלים מרכז` | `אגריפס 40` |

### אם לא נמצאה כתובת מדויקת
**לא לכלול את העסק בטבלה.** עדיף פחות שורות עם נתונים אמינים מאשר שורות עם כתובות כלליות.

---

## תנאי עצירה — כלל ברזל

**אסור להפסיק את החיפוש לפני שמתקיים אחד משני התנאים הבאים:**

1. **נמצאו 50 נכסים לבדיקה בדירוג "גבוה"** — זהו היעד המועדף. רק לאחר הגעה ל-50 נכסים כאלה מותר לסיים ולהפיק את הקובץ.
2. **נוצלו 10,000 טוקנים** — אם הגענו למגבלת הטוקנים לפני שהגענו ל-50, יש לעצור, להפיק את הקובץ עם מה שנמצא עד כה, ולציין למשתמש כמה נכסים נמצאו ומדוע החיפוש הופסק.

**חל איסור מוחלט לעצור את החיפוש מסיבות אחרות** — לא בגלל "מצאתי מספיק", לא בגלל שנגמרו מקורות ברורים, ולא בגלל שעברנו על 50 עסקים כולל דירוגים נמוכים. רק 50 נכסים בדירוג **גבוה**, או 10,000 טוקנים.

## תהליך החיפוש

### 1. חיפוש מרובה מקורות
לכל קטגוריה עסקית, חפש ב:
- אתרי האקסל של העסקים עצמם (מקור ראשוני — עדיף)
- דפי זהב (`d.co.il`)
- B144 (`b144.co.il`)
- רוטר (`rotter.net`)
- זיפס (`zips.co.il`)
- THE INDEX (`theindex.co.il`)
- אתרי הרשתות המקצועיות (מכבידנט, אלפא-וט וכד')

### 2. אימות כתובת
לכל עסק — ודא שהכתובת (רחוב + מספר) מופיעה במקור מאמין לפני ההכללה.
אם הכתובת מופיעה רק ב"ירושלים" או "אזור ירושלים" — **לא לכלול**.

### 3. קטגוריות ויחס הכמויות
כאשר המשתמש מבקש 50 עסקים, חלוקה מומלצת:
- ~15 מרפאות שיניים
- ~15 משרדי עורכי דין
- ~10 משרדי רואי חשבון
- ~10 מרפאות וטרינריות

(ניתן להתאים לפי מה שנמצא בפועל עם כתובות מאומתות)

## בניית קובץ האקסל

### עמודות (בסדר זה, מימין לשמאל — RTL)
1. **שם העסק** — שם בלבד, ללא תיאורים
2. **כתובת** — רחוב + מספר (+ שכונה אם רלוונטי), ללא "ירושלים"
3. **סוג עסק** — מתוך הרשימה: `מרפאת שיניים` / `משרד עורכי דין` / `משרד רואי חשבון` / `מרפאה וטרינרית`
4. **קישור למקור** — ה-URL ממנו נלקחו הנתונים

### עיצוב
```python
import openpyxl
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

# כותרת
header_fill = PatternFill(start_color="1F4E79", end_color="1F4E79", fill_type="solid")
header_font = Font(name="Arial", bold=True, color="FFFFFF", size=11)

# צבע לפי קטגוריה
cat_colors = {
    "מרפאת שיניים":    "FFF3CD",  # צהוב בהיר
    "משרד עורכי דין":  "D4EDDA",  # ירוק בהיר
    "משרד רואי חשבון": "D1ECF1",  # כחול בהיר
    "מרפאה וטרינרית":  "F8D7DA",  # ורוד בהיר
}

# גבולות דקים לכל תא
thin = Border(
    left=Side(style='thin'), right=Side(style='thin'),
    top=Side(style='thin'), bottom=Side(style='thin')
)

# יישור: עמודות A-C — ימין; עמודה D (קישור) — שמאל
# גובה שורות: כותרת=30, נתונים=20
# רוחב עמודות: A=42, B=42, C=22, D=55
# הקפאת שורת כותרת: ws.freeze_panes = "A2"
# כיוון RTL: ws.sheet_view.rightToLeft = True
```

### שם הקובץ
הקובץ נשמר תמיד בפורמט:
```
עסקים לבדיקה מהאינטרנט DD.MM.YYYY.xlsx
```
לדוגמה: `עסקים לבדיקה מהאינטרנט 30.04.2026.xlsx`

```python
from datetime import date
today = date.today().strftime("%d.%m.%Y")
filename = f"עסקים לבדיקה מהאינטרנט {today}.xlsx"
wb.save(f"/mnt/user-data/outputs/{filename}")
```

### מה לא לכלול
- **אין מקרא** בתחתית הגיליון (הצבעים מספיקים)
- **אין עמודת "עיר"** — ברור שהכל ירושלים
- **אין סיכומים / פורמולות**
- **חל איסור מוחלט להכניס לאקסל עסקים שאינם בדירוג "גבוה"** — גם אם נמצאו עסקים בדירוג "בינוני" או "נמוך", הם נשארים מחוץ לקובץ הסופי לחלוטין. הקובץ מכיל **אך ורק** נכסים בדירוג **גבוה**.

## קוד Python שלם לדוגמה

```python
import openpyxl
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

wb = openpyxl.Workbook()
ws = wb.active
ws.title = "עסקים בירושלים"

headers = ["שם העסק", "כתובת", "סוג עסק", "קישור למקור"]
header_fill = PatternFill(start_color="1F4E79", end_color="1F4E79", fill_type="solid")
header_font = Font(name="Arial", bold=True, color="FFFFFF", size=11)
thin = Border(
    left=Side(style='thin'), right=Side(style='thin'),
    top=Side(style='thin'), bottom=Side(style='thin')
)

for col, h in enumerate(headers, 1):
    c = ws.cell(row=1, column=col, value=h)
    c.font = header_font
    c.fill = header_fill
    c.alignment = Alignment(horizontal="center", vertical="center", wrap_text=True)
    c.border = thin

cat_colors = {
    "מרפאת שיניים":    "FFF3CD",
    "משרד עורכי דין":  "D4EDDA",
    "משרד רואי חשבון": "D1ECF1",
    "מרפאה וטרינרית":  "F8D7DA",
}

# data = רשימת טאפלים: (שם, כתובת, סוג, קישור)
for row_idx, (name, address, btype, url) in enumerate(data, 2):
    fill = PatternFill(start_color=cat_colors[btype],
                       end_color=cat_colors[btype], fill_type="solid")
    for col_idx, value in enumerate([name, address, btype, url], 1):
        cell = ws.cell(row=row_idx, column=col_idx, value=value)
        cell.font = Font(name="Arial", size=10)
        cell.fill = fill
        cell.alignment = Alignment(
            horizontal="right" if col_idx != 4 else "left",
            vertical="center", wrap_text=True)
        cell.border = thin

ws.column_dimensions['A'].width = 42
ws.column_dimensions['B'].width = 42
ws.column_dimensions['C'].width = 22
ws.column_dimensions['D'].width = 55
ws.row_dimensions[1].height = 30
for row in range(2, len(data) + 2):
    ws.row_dimensions[row].height = 20

ws.freeze_panes = "A2"
ws.sheet_view.rightToLeft = True

from datetime import date
today = date.today().strftime("%d.%m.%Y")
filename = f"עסקים לבדיקה מהאינטרנט {today}.xlsx"
wb.save(f"/mnt/user-data/outputs/{filename}")
```

לפני הפקת הקובץ הסופי, עבור על כל שורה ובדוק:
- [ ] יש רחוב + מספר בעמודת הכתובת?
- [ ] לא כתוב "ירושלים" בכתובת?
- [ ] שם העסק — שם בלבד (ללא תיאורים כמו "מרפאה מצוינת")?
- [ ] הקישור מוביל למקור שממנו נלקחה הכתובת?
- [ ] העסק מסוג שדורש שטח מסחרי (לא עסק שיכול לפעול מבית)?
- [ ] העסק בדירוג **גבוה** בלבד — אם לא, **לא לכלול בקובץ**?
